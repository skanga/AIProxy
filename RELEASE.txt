AIProxy 5.7

Maintenance release with clearer oversized-response errors and internal cleanup.

Oversized-response errors now include the configured byte limit. Shutdown handling is simplified while retaining structured logging. Unused helpers and warning suppressions have been removed, and documentation numbering and examples have been corrected.

Requires Java 21 or newer. Download AIProxy-5.7.jar and run java -jar AIProxy-5.7.jar.
