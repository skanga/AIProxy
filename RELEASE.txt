AIProxy 5.6

Startup inference checks now report upstream streaming errors instead of misleading missing-content warnings. For example, Codex Subscription Sharing usage limits are shown directly even when the HTTP response status is 200.

Errors still fail the startup check if partial response text arrived first. Displayed upstream error messages are limited to 1,024 characters and control characters are sanitized. Streams without text or explicit errors retain the existing missing-content diagnostic.

Includes regression coverage for errors before and after partial text, oversized messages, missing or invalid messages, and control characters. Authentication, routing, and failover behavior are unchanged.

Requires Java 21 or newer. Download AIProxy-5.6.jar and run java -jar AIProxy-5.6.jar.
