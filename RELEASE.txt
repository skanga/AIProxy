AIProxyOauth 4.1
===============

Keep all proxy-managed logins together in ~/.aiproxyoauth on every platform.

Changes:
- Default Copilot credentials to ~/.aiproxyoauth/copilot-auth.json.
- Default native Codex credentials to ~/.aiproxyoauth/codex-auth.json.
- Default Anthropic credentials to ~/.aiproxyoauth/anthropic-auth.json.
- Preserve explicit CLI > environment > YAML credential-path overrides.
- Preserve separate Codex CLI/device-login credential paths and discovery.
- Update configuration examples and add default-path and precedence tests.

Migration:
- Existing files are not automatically moved or discovered at the former
  LOCALAPPDATA/AIProxyOauth, XDG_CONFIG_HOME/AIProxyOauth, or
  ~/.config/AIProxyOauth defaults.
- Log in again to save credentials at the new defaults, or configure the
  existing file paths for both login and serving.
- In Codex auto mode, a missing native file at the new default allows CLI
  credential discovery as usual. Use native mode to require native login.
- This release changes directory organization; file-permission behavior
  and plaintext credential storage are unchanged.

Validation:
- 613 Java tests and 7 offline Python compatibility-tool tests pass.
- Live provider login was not tested for this release.

Requires Java 21 and an account with access to the selected provider/model.

Download AIProxyOauth-4.1.jar and run:
  java -jar AIProxyOauth-4.1.jar --help
