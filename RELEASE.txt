AIProxy 5.1
===========

Expand offline regression coverage for authentication commands, request
validation, and streaming, with 136 additional Java tests since 5.0.

Changes:
- Cover auth status, credential redaction, login option forwarding, exit codes,
  interruption handling, logout preservation, and key command behavior.
- Test native OAuth endpoint trust, token lifetimes, account changes,
  refresh identity preservation, and revocation responses.
- Exercise malformed Chat Completions and Responses requests, along with
  reasoning and tool-result content preservation.
- Cover native Codex request restrictions and nested tool validation.
- Test invalid Messages stream lifecycles, incomplete frames, and handling
  of future event and block types.
- Remove the unused BoundedBodyReader.BodyTooLargeException.maximumBytes()
  accessor. HTTP APIs and credential locations are unchanged.

Validation:
- 773 Java tests and 33 offline Python tests pass.
- Fat JAR builds with Java 21; version command reports AIProxy 5.1.
- Live provider authentication and inference were not tested for this release.

Requires Java 21 and an account with access to the selected provider/model.

Download AIProxy-5.1.jar and run:
  java -jar AIProxy-5.1.jar --help
