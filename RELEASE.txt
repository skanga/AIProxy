AIProxyOauth 3.1.1
=================

Clearer startup diagnostics, consistent test-model selection, and a README
focused on downloading and using the proxy.

Changes:
- Startup Auth lines consistently identify credential sources and profiles.
- Model status distinguishes discovery, fresh/stale caches, built-in fallback,
  configured lists, and unavailable catalogs across providers.
- Discovery failures appear in startup warnings. Doctor reports degraded
  catalogs with a nonzero exit code.
- Startup inference checks prefer the first model containing luna or haiku
  (case-insensitive), otherwise the last model in the list.
- Remove unchecked compiler warnings from native OAuth and transport tests.
- Rewrite the README around release downloads, login, client setup,
  configuration, API keys, and troubleshooting.

Requires Java 21. Provider login and inference depend on account access.
Live provider access was not retested for this release.

Download AIProxyOauth-3.1.1.jar and run:
  java -jar AIProxyOauth-3.1.1.jar --help
