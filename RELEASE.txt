AIProxy 5.4
===========

Share inference timeouts and diagnostics across providers, and enforce explicit
generation parameters rather than silently changing or discarding them.

Changes:
- Apply a shared 60-second read-idle timeout to inference response bodies,
  including error bodies and native Messages. OAuth transport is unchanged.
- Return HTTP 504 before downstream commitment on read timeout; after commitment,
  retain the status and terminate with a protocol-appropriate error where possible.
- Return X-Request-Id and safe upstream correlation IDs. Record original upstream
  status and machine-readable error categories without requiring payload logging.
- Preserve upstream rejection explanations. Do not infer content filtering from
  HTTP 422 alone, rewrite rejected content, or retry policy/validation rejections.
- Share numeric and token-limit validation across Chat and Responses. Preserve
  omitted output limits; apply required Messages defaults within known model limits.
- Check catalog/profile capabilities for execution and failover. Explicit settings
  are not changed between attempts; failover remains opt-in.
- Align model parameter reporting and document migration requirements.

Breaking corrections and migration:
- Codex CLI/native explicit max_tokens, max_completion_tokens, and max_output_tokens
  now return 400 instead of being silently ignored. Remove these fields only if
  an upstream-selected budget is acceptable, or use a provider that honors them.
- Explicit reasoning effort is no longer silently clamped. Use an advertised value
  or omit it to retain model/alias defaults.
- Conflicting Chat token-limit aliases and generation fields from the wrong API
  now return 400. Equal token-limit aliases remain accepted.
- Normalized Responses translations reject unsupported non-null reasoning options,
  such as reasoning.summary, instead of dropping them. Codex retains its separate path.
- Messages translation requires advertised compatible adaptive thinking and rejects
  sampling controls combined with translated thinking. Native Messages stays native.
- Unknown sampling support or output limits exclude a fallback candidate. Primary
  requests may still defer unknown sampling restrictions to upstream validation.

Validation:
- 875 Java tests pass, including cross-provider contracts and local stalled HTTP reads.
- 33 offline Python tooling tests pass; the fat JAR reports AIProxy 5.4.
- The local test/package build passed; local clean was blocked by the existing
  target directory. Release CI performs a clean build on Ubuntu.
- No live provider authentication/inference or load testing was performed.
- Retrying a timeout can duplicate billable upstream work.

Requires Java 21 and an account with access to the selected provider/model.

Download AIProxy-5.4.jar and run:
  java -jar AIProxy-5.4.jar --version
  java -jar AIProxy-5.4.jar serve
